# TONUS – Live-Demo Massagepraxis

Interaktiver Prototyp einer Website mit Online-Buchung für eine (fiktive) Praxis für Sport- & Medizinische Massage in Augsburg.

**Live:** https://911911911911911.github.io/tonus-massage-demo/

## Funktionen
- Landingpage mit Leistungen & Preisen (DE / EN umschaltbar)
- Online-Buchung: Beschwerden-Auswahl mit Behandlungsempfehlung, Schmerzskala, Therapeut:innen-Wunsch, Datum & Uhrzeit, Gesundheitscheck
- Chat-Assistent mit FAQ (Vorbereitung, Krankenkasse, Parken, Stornierung …)
- Praxis-Dashboard: neue Buchungen erscheinen live inkl. digitalem Anamnesebogen

## Lokal starten
`index.html` herunterladen und im Browser öffnen – keine Installation nötig (Tailwind CSS via CDN).

> Hinweis: Demo – alle Namen, Preise und Daten sind fiktiv. Es werden keine Daten gespeichert oder versendet.
